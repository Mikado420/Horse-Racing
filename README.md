# オンライン競走馬オーナーズ（仮）

競走馬を育成し、レースに出走させて賞金を積み上げるブラウザゲームです。
製品版の主目的はプレイヤー同士のオンライン対戦ですが、開発は **オフライン先行** で進めています。
オフライン版（ひとりで遊ぶ）は、育成・レース・経済バランス・3D演出を検証するための開発用モードです。

## 構成

```
shared/   ゲームのルールと計算（画面にもサーバーにも依存しない。依存ライブラリなし）
  race.ts       レース計算（シード付きで再現可能）
  resolve.ts    1レースの確定：着順・賞金・馬の状態変化（オフライン/オンライン共通）
  horse.ts      育成ルール（調教・休養・故障・成長・競走生活）
  programs.ts   レース番組（クラス・賞金・出走条件・CPUの強さ）
  cpu.ts        CPU馬の生成
  market.ts     馬の販売・引退報奨金
  economy.ts    経済の定数、コース定義
client/   React + Vite + React Three Fiber
  src/offline/  オフライン版のエンジン（純粋関数）・セーブ/ロード・画面
  src/three/    3D競馬場とレース再生（表示のみ。計算はしない）
  src/screens/  共通画面（厩舎・馬の詳細・レース観戦）とオンライン用画面
server/   オンライン対戦用（Node.js・PostgreSQL・Colyseus）
```

画面は `Backend` という共通の窓口（`client/src/backend.ts`）を通してデータを扱います。
オフラインはブラウザ内のエンジン、オンラインはサーバーAPIが同じ形で応えるので、厩舎・馬の詳細・初期馬選択の画面は両モードで共用です。

## 遊び方（オフライン：サーバー不要）

```bash
npm install
npm run dev:client      # http://localhost:5173 を開いて「ひとりで遊ぶ」
```

1. オーナー名を決めて初期馬（3タイプ）を選ぶ
2. 調教（10,000円・疲労が増える）と休養（無料・疲労回復）で仕上げる
3. 「レース」でクラスを選び、CPU馬7頭と走る。「今の状態で勝率を見積もる」で事前に勝率と期待収支を確認できる
4. 賞金で新しい馬を買い、勝ち上がってより上のクラスへ

| クラス | 条件 | 1着賞金 | 出走経費 | 相手の能力 |
|---|---|---|---|---|
| 未勝利戦 | 未勝利の馬 | 112,000円 | 3,000円 | 44〜58 |
| 一般戦 | なし | 200,000円 | 5,000円 | 50〜66 |
| 翠ヶ丘特別 | 1勝以上 | 442,000円 | 15,000円 | 64〜82 |
| 翠ヶ丘記念 | 3勝以上 | 1,102,000円 | 40,000円 | 78〜96 |

- **競走生活**：調教・休養・出走のたびに1ターン進み、60ターンで引退。若いうちほど能力が伸びやすい。引退時に戦績に応じた報奨金
- **馬を買う**：お手ごろ（15万円）・期待馬（40万円）・良血（100万円）。3レースごとに入れ替わり。厩舎は5頭まで
- **記録**：これまでの馬の獲得賞金順、クラス別の勝利数と最高タイム
- **検証**：同じ条件のレースを全クラスで50〜500回計算し、勝率・平均着順・期待収支を表示。能力や疲労・調子を仮に変えて試せる（セーブは変わらない）
- **セーブ**：操作のたびにブラウザ（localStorage）へ自動保存。厩舎画面からファイルへの書き出し・読み込み・最初からやり直しができる。壊れたデータは読み込み時に検出して退避する

数値の調整は `shared/src/programs.ts`（クラスと賞金）、`economy.ts`（所持金・調教費）、`horse.ts`（育成）、`race.ts`（レース）、`market.ts`（販売価格）に集約しています。

### バランスの目安（自動テストで確認）

- 初期馬（3タイプとも）：未勝利戦の勝率 40〜55%、一般戦 10〜20%、特別戦・記念はほぼ勝てず記念は赤字
- 3タイプの直接対決はどれも勝率 53〜56% の範囲
- 単純な方針の自動プレイで1頭の競走生活（60ターン）を最後まで進めると、およそ17戦6〜8勝で所持金が約240万〜260万円（開始時30万円）。次に期待馬や良血馬を買える程度

## オンライン対戦（試作）

```bash
docker compose up -d                    # PostgreSQL（または手元の PostgreSQL 14 以上）
cp server/.env.example server/.env
npm run dev:server                      # http://localhost:2567（API + WebSocket）
npm run dev:client                      # 「オンライン対戦」を選ぶ
```

- 2〜8頭。最初の登録から30秒で締切、2頭未満なら延長、8頭で即発走
- 締切の瞬間にサーバーがDBから能力を読み直し、オフライン版と同じ `resolveRace` で着順・賞金を決めて1トランザクションで保存してから全員に配信。クライアントの値は使わない
- 同じレースの二重精算はレースIDの主キー制約で防止。通信が切れても判定と賞金付与は変わらず、90秒以内なら再接続して観戦に戻れる
- 入力検証、レート制限、所有者チェック、残高チェック（行ロック）

## 知的財産について

競馬場名・レース名・ゲーム名・画面デザイン・ゼッケン配色・馬名の生成パターン・文章はすべて本作独自のものです。既存ゲームの名称・画像・音楽・データは使用していません。
脚質（逃げ・先行・差し・追込）や着差（ハナ・クビ・馬身）は実際の競馬で一般的に使われる用語です。
