## 3. 発見した問題と原因

### 3-1. 内部のエネルギー値から「スタミナ切れ」を断定している
`emptyRemain` は内部エネルギーが0になった地点です。3年分・486レース・3,888頭を計算して確認したところ、
エネルギーが0になる馬は全体の **21.5%** で、そのうち **34%** は3着以内に入っていました。
内部値だけで「脚が上がった」「スタミナ切れが敗因」と言える根拠はありません。

### 3-2. 調教師のレース後コメントに事実と食い違う文が出る
- `blockedSec` は場所を問わない合計なのに、常に「**直線で**前が詰まる不利がありました」と言う
- 出走前の意見が「反対」だったときは、**勝っても**「やはり今回は無理をさせたと思います」と言う
- 3-1 の内部値で「脚が上がっています」と言う

### 3-3. 個性の兆候が、記録ではなく真の値と乱数で決まっている（ランダムな誤情報の主な発生源）
`raceTraitSignChance` は「その馬が本当にその個性を持つか」で兆候の確率を変え、持たない馬にも2%の確率で兆候を出します。
走りの内容と矛盾する兆候（例：行きたがる素振りがあったレースで「折り合いが良い」かもしれない）も出ます。

同じ486レースで、レース記録から観察できる行動が個性の有無でどれだけ違うかを測りました。

| 個性 | 観察できる行動 | 個性あり | 個性なし | 尤度比 |
|---|---|---|---|---|
| 行きたがる | 道中で騎手に逆らう（4秒以上） | 83.5% | 0.24% | 355 |
| 逃げへの執着 | 作戦が逃げでないのに先頭で運ぶ | 13.5% | 6.2% | 2.2 |
| 勝負根性が強い | 競り合いで前に出る | 8.1% | 7.4% | 1.1 |
| 末脚型 | 上がり最速 | 20.0% | 11.5% | 1.7 |
| 馬群が苦手 | 馬群にいて順位を落とす | 16.8% | 20.9% | 0.8 |
| 外を回るのが得意 | 外を回っても上がり上位 | 10.7% | 19.9% | 0.5 |
| 折り合いが良い | 行きたがる素振りがない | 73.7% | 66.5% | 1.1 |

1レースの記録から判断できるのは「行きたがる」だけです。ほかの個性は、記録からは持っている馬と持っていない馬の区別がつきません。

### 3-4. 週報で、個性を持たない馬にも兆候を報告する
`stable.ts` は個性を持たない馬にも毎週 0.4%×（調教師の精度）の確率で兆候を報告し、「調教で行きたがる素振りを見せた」のように起きていない出来事を事実として書きます。

### 3-5. 内部の数値をそのまま表示している
上の表の「内部」の項目（速度 m/秒、エネルギー切れ地点、詰まった秒数、余分に走った距離、行きたがった秒数、仕掛けた地点の正確な距離）。

### 3-6. ラップの合計が走破タイムと合わない距離がある
`leaderLaps` はスタートから200mごとなので、1300m・1500m・1700m・2100m のように200mの倍数でない距離では最後の100mが欠けます。
200mの倍数の距離では、合計は勝ち時計と0.06秒以内で一致することを確認しました（486レース）。

### 3-7. 「通過順」が「コーナー通過順位」ではない
記録されているのは地点ごと（スタート後400m・残り800/400/200m・ゴール）の通過順です。コーナーでの通過順は記録されていません。

## 4. 方針（フェーズ2以降）

- 分析の情報を **記録・観察・推定・提案** の4つに分け、推定には必ず根拠（どの観察から言えるか）を持たせる。根拠が足りないときは「特定できない」と言う
- 調教師のレース後コメントは、上の分類から組み立てる。文面の言い回しは選べるが、意味（どの観察・推定を述べるか）は記録だけで決まる
- 個性の兆候は記録から決める（真の値を見ない）。1レースで判断できるのは「行きたがる」だけ。週報の偽の兆候は出さない
- 内部の数値は画面に出さない。検証タブは開発者向け設定の内側に移す
- 既存のセーブに保存されている古いコメントは、読み込み時に記録から作り直す（セーブの形式は変えない）
- レース計算は変えない（既存の「結果固定」テストで確認する）

## 5. 今回は変えないもの（判断の理由）

- **能力・適性の見立て（推定）**：馬主モードの中心の仕組みで、証拠の誤差は表示する「確かさ」に織り込まれています。既存テストで「数値まで判明した能力の85%以上が真の値±6以内」を確認しています。ただし、レース後の見立て更新に使う証拠は「レース条件から決めた情報量で、真の値に誤差を加えたもの」で、記録から直接導いた値ではありません。記録からの導出に作り替えるかは、ゲームの設計に関わるため今後の検討事項とします
- **調教時計**：調教師ごとの偏りを含む観測値から作っています。「その厩舎の調教条件の違い」と解釈できますが、計測値としては不自然なので今後の検討事項とします

## 6. 実施した対応（フェーズ2〜5）

| 問題 | 対応 | 確認するテスト |
|---|---|---|
| 3-1 内部エネルギー値からの断定 | 報告・コメント・分析の文章で使わない。持久力の判断材料は「記録に表れた終盤の伸び（残り400mからの順位・上がり3Fの順位）」で決める | 内部のエネルギー残量だけでは報告もコメントも変わらない |
| 3-2 事実と食い違うコメント | `report.ts` の報告（記録・観察・推定・提案）から組み立てる。場所が記録されていない不利は場所を言わない。出走前の意見と結果を結び付ける文は削除。2・3着でも勝ち馬と2馬身以上離れていれば「上位争い」と言わない | コメントで触れた出来事がすべて記録で確かめられる／勝ったレースで敗因を推定しない |
| 3-3 真の個性と乱数で決まる兆候 | `raceTraitEvidence`：記録に表れた行動だけで決める。対象は「行きたがる」のみ | レースでの個性の兆候は記録だけで決まる |
| 3-4 週報の偽の兆候 | 個性を持たない馬には兆候を出さない（乱数の消費順は変えない）。観察コメントは「印象」の表現に | 週報で個性のない馬に兆候を出さない／週報の観察は「印象」 |
| 3-5 内部の数値の表示 | 分析・結果パネルから削除。検証タブは開発者向け設定の内側へ | 報告に内部の数値が含まれない（ブラウザでも画面の文字を確認） |
| 3-6 ラップの欠け | 最後の区間（100m）を勝ち時計から補う。合計が勝ち時計と0.06秒以内で一致するかを `lapsConsistent` で持つ | ラップ合計＝勝ち時計（200mで割り切れない距離も） |
| 3-7 通過順 | 地点名で表示し、通過した順に並べる。序盤の位置は400m地点の通過順に統一。「コーナーごとの通過順は記録していません」と明記 | 通過順は通過した順に並ぶ |
| 旧セーブのコメント | 読み込み時に記録から作り直す（形式は変えない、何度実行しても同じ） | client の移行テスト3件 |

ペースの判断基準は、最初の測定（全距離まとめて）では短距離戦が常に「前半がゆったり」になってしまったため、
スタート直後の200mを除き、距離帯ごとの基準（レース1,292回の計算）に改めた。

## 7. 未解決・今後の候補

- **能力の見立ての証拠**：レース後・分析時の見立て更新は「レース条件から決めた情報量で、真の値に誤差を加えた値」を証拠にしている。表示する確かさとは整合している（既存テスト：数値まで判明した能力の85%以上が真の値±6以内）が、記録から直接導いた値ではない
- **調教時計**：調教師ごとの偏りを含む観測値から作っている
- **コーナー通過順・先頭争い**：記録していない。追加するにはレース計算の記録項目を増やす必要がある（結果は変わらない形で可能）
- **「上位争い」「大差」の基準**：着差はタイム差から換算しているため、長距離では2・3着でも大差になることが多い
