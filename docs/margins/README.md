# レース着差の現実化（v2.1）

> その後、既定のレース計算はレース計算 v3（`docs/race-sim`）になった。この文書の「変更後」は v2.1 の値で、`withConfig({ race: RACE_V21 })` で同じ結果を再現できる。

実装指示書「レース着差の現実化と競走結果のバランス改善」の作業記録。
1着が2着以下を大きく引き離す（着差の中央値が約7馬身、3レースに1回は10馬身超の大差）原因を調べ、計算式を最小限変更した。

- 対象：オフライン版（馬主モード）のレース計算 `shared/src/owner/sim.ts`（係数は `shared/src/owner/config.ts` の `race`）
- 着差を後から縮める処理・上限・接戦の強制・表示だけの変更・乱数の追加は**していない**。着差はこれまでどおりゴール通過時刻の差から計算している
- 変更前の計算は `LEGACY_RACE_V20`（config.ts）を渡すとそのまま再現できる。v2.0 の固定値テスト（ハッシュ 2309594831）はこの設定で今も一致する

## 1. 測り方

`scripts/margin-stats.ts`：通常の番組6年分＋全重賞（各年4回分）＝1組 2,064 レース、CPU馬8頭立て。
番組・CPU馬・レースのシードはすべて番号から決まるので、変更前と変更後を**同じ条件**で比べられる。
シード組 1〜3 で調べて調整し、調整に使っていないシード組 4〜6 で確かめた。

```
npx tsx scripts/margin-stats.ts docs/margins/after-123.json                     # 変更後・シード組1〜3
npx tsx scripts/margin-stats.ts docs/margins/before-123.json --legacy            # 変更前・シード組1〜3
npx tsx scripts/margin-stats.ts docs/margins/after-456.json --seeds 4,5,6        # 変更後・独立したシード
npx tsx scripts/margin-steps.ts docs/margins/steps.json                          # 変更を1つずつ入れたときの変化
```

着差の換算はゲーム内の表示と同じ（1馬身 = 2.4m、タイム差 1秒 = 16.5m）。

| 指標 | 意味 |
|---|---|
| 着差中央値・90%・95% | 1着と2着の差（馬身）の分布 |
| 0.05秒未満 | 1-2着のタイム差が公式表記の「0.0秒差」に当たる割合（ハナ・アタマ・クビ程度） |
| 0.5秒以上 | 1-2着のタイム差が 0.5秒（約3.4馬身）以上の割合 |
| 大差 | 1-2着が10馬身を超えた割合 |
| 1-2着・1-3着（勝ち時計比） | タイム差を勝ち時計で割った値の平均（下の英国の研究と同じ定義） |
| 能力1位の勝率 | 6能力の平均が出走馬中1位の馬が勝った割合 |
| エネルギー切れ | ゴール前にエネルギーが尽きた馬の割合（1頭あたり） |

- 1-2着の差は勝ち時計の **0.3%前後**（1600m なら約 0.3秒・約2馬身）。0.0秒差の勝ちは 0.5秒以上の勝ちより**ずっと多い**（JRA で約2.3倍）

## 4. 原因の切り分け

### 4-1. 入力を順にそろえる（344レース・良馬場）

| 出走馬の入力 | 1-2着 中央値 | 90%点 | 1着-最下位 |
|---|---|---|---|
| そのまま | 0.93秒 | 3.10秒 | 5.91秒 |
| 状態（調子・疲労・仕上がり・経験）をそろえる | 0.87 | 2.54 | 5.10 |
| ＋適性・個性もそろえる | 0.70 | 2.39 | 3.59 |
| ＋能力もそろえる | 0.37 | 1.50 | 2.21 |
| ＋作戦もそろえる（全頭同じ馬） | 0.19 | 0.78 | 1.18 |

**全く同じ馬8頭でも1-2着が0.19秒、最下位まで1.2秒開いていた**。入力の差だけでなく、レースの進み方そのものが差を広げていた。

### 4-2. 道中の隊列

先頭が残り800m・400m地点を通過した時点の、先頭と2番手・最後方の差（中央値）：

| 距離帯 | 2番手との差（残り800m） | 先頭〜最後方（残り800m） | 先頭〜最後方（残り400m） |
|---|---|---|---|
| 短距離 | 3.2m | 24m | 51m |
| マイル | 6.8m | 45m | 70m |
| 中距離 | 13.0m | 67m | 91m |
| 長距離 | 19.3m | 107m | 127m |

直線に入る前に先頭が5〜8馬身抜け出し、隊列が 100m 以上に伸びていた。

### 4-3. 原因

| # | 原因 | 根拠 |
|---|---|---|
| A | **馬群の連動がない**。道中の目標速度が「自分の最高速度 × 脚質ごとの割合」だけで決まり、前の馬との関係を見ていなかった。最高速度が1%違えば、道中の全区間で1%ずつ差が積み上がる | 4-2。全く同じ馬でも差が開く（4-1） |
| B | **長距離でほぼ全頭がエネルギー切れ**。エネルギーは「速度の2乗 × 距離」で減る一方、道中のペースは距離によらず一定だったため、2500m以上では97%の馬が途中で尽き、尽きた順に大きく遅れた | エネルギー切れ：短距離0%・中距離35%・長距離97%。距離別の平均速度がほぼ一定（1200m 16.53 → 3000m 16.23 m/秒） |
| C | **能力・状態の差がタイムに強く出すぎる**。スピード1あたり最高速度が約0.18%変わり、未勝利と重賞の勝ち時計の差が 1600m で 5.6%（実際は約2.5%）、2400m で 7.0%（実際は約2%）。調子1段階で1.2%など、状態・適性の補正も同じ尺度で大きい | 2章のクラス別勝ち時計。単独の感度：スピード+10 で 1600m 1.03秒、調子+1 で 0.62秒 |
| D | 競り合いの効果が「1.6m以内なら一律」で、勝負根性の強い先頭馬が1.6mの境目で相手を止め続け、着差が 0.08〜0.10秒に不自然に集まる | 1-2着のタイム差の分布に 0.08〜0.10秒の山 |
| E | エネルギーが尽きた瞬間に目標速度が最高速度の約89%へ切り替わる（不連続） | 計算式 |

二次的な要素：加速力・スタミナ・パワー・根性・賢さを単独で+10しても、変更前は 0.02〜0.21秒しか変わらず、着差の主因ではなかった。
CPU馬の能力の分布（クラスごとの水準の幅＋能力ごとのばらつき）は、出走馬の総合能力の最大−最小が平均11.8で、これ自体は変えていない（Cの換算を直せば差は自然に縮む。分布を狭めると能力差そのものを消すことになるため）。

## 5. 変更した計算式と理由

係数はすべて `config.ts` の `race` にある。`LEGACY_RACE_V20` の値を渡すと変更前に戻る。

| # | 変更 | 計算式 | 理由（対応する原因） |
|---|---|---|---|
| ① | 馬群について行く | 道中、前方 `followRange`=20m 以内に馬がいれば、目標速度 = max(自分の巡航速度, min(前の馬の速度, 最高速度×`followMaxFraction`=0.97, 走り切れる速度×`followOverPace`=1.02)) | A。実際のレースでは道中は馬群がまとまって流れ、能力差は主に終盤の脚と消耗に出る。ついて行く分はエネルギーを多く使う |
| ② | エネルギーに有酸素分を入れ、道中を配分する | 消費（1秒あたり）= 消費倍率 ×（(v/17.5)² × v − `aerobicRate`=7.9）。エネルギー量 = `energyScale`=0.565 ×（700＋27×スタミナ）×…。道中の巡航速度は「仕掛け地点から先を最高速度で走る分を残して、仕掛けまで一定速度で走り切れる速度」（`staminaPacing`=1）を上限にする | B。速度の2乗だけだと距離が倍になると持つ速度が約3割落ち、現実の距離と速度の関係（2400mで1600mの約96%）に合わない。運動生理学の臨界速度モデル（有酸素で賄える速度＋無酸素の余力）と同じ形にした。係数は「スタミナ60の馬が1600mでは余裕があり、3000m前後でちょうど使い切る」ように決めた |
| ③ | 距離に応じた道中のペース | 道中の割合 ×（1 − `cruisePerKm`=0.05 ×（距離−1600）/1000）、上限 0.99 | B。騎手は距離に合わせて道中のペースを決める。東京芝1勝クラスの平均速度（2000m 0.979・2400m 0.963）に合わせた（変更後 0.993・0.966） |
| ④ | 競り合いの効果を連続に | 効果 ×（1 − `duelTaper`=1 ×（1 − 近さ））、近さ = 1 − 前後の差/1.6m | D。並んでいるほど強く効き、離れると連続的に弱まる。境目で着差が固定される不自然さをなくした |
| ⑤ | エネルギー切れの手前から徐々に失速 | 残りが最初の `fadeReserve`=10% を切ると、上限速度を「尽きたときの速度」へ向けて連続的に下げる | E。尽きた瞬間の不連続をなくす |
| ⑥ | 馬ごとの速度差の換算を縮める | 能力値（スピード・加速・スタミナ・パワー）は 60 を中心に差を `differenceScale`=0.5 倍、芝ダート・回り・小回り・脚質の適性、状態（調子・疲労・仕上がり）、その日の出来による補正も 1 からのずれを 0.5 倍 | C。未勝利と重賞の勝ち時計の差を現実（1600m 約2.5%）に近づけた（変更後 2.8%）。能力・適性・状態の**相対的な重み（どれがどれだけ効くか）は変えていない**ので、強い馬が勝ちやすい関係は保たれる（7章）。距離適性（v1.3 の補正表）と馬場全体の重さは対象外 |
| ⑦ | スタートのばらつきを縮める | 出遅れ = 乱数 × 0.45 ×（1.25 − 賢さ/140）× `startDelayScale`=0.5 | ⑥で能力差の換算を縮めたため、能力と関係しない出遅れ（最大約0.4秒）の比重が相対的に大きくなり、能力1位の勝率が 26.6% → 24.7% に下がった。これを戻すため（26.1%）。乱数は増やしておらず、幅を縮めただけ |

分析機能（`report.ts` の `ANALYSIS_RULES`）も、レースの進み方が変わったので同じ方法で計算し直した：
- ペースの判定（距離帯ごとの15%点・85%点）：1,292レースで再計算
- 出遅れの判定：0.35秒 → 0.175秒（⑦でばらつきを半分にしたため。該当する馬の割合は変更前 9.4%・変更後 8.4%）

試したが採用しなかったもの：
- 道中で作戦より前に出すぎた馬を下げる（2%減速）：着差が逆に広がった
- 前の馬の後ろで折り合う（前の馬が遅ければ合わせる）：長距離の改善がなかった
- エネルギー切れ時の速度だけを上げる（0.89 → 0.95）：ほとんど変わらない（着差中央値 6.96 → 6.93）

## 11. 残っている課題

- **接戦の割合はまだ現実より少ない**。0.0秒差（0.05秒未満）の勝ちは 2.0% → 12.6%、0.5秒以上は 70.4% → 20.1% に改善したが、JRA では 0.0秒差の勝ちが 0.5秒以上の勝ちの約2.3倍あるのに対し、ゲームでは約0.6倍。頭数（ゲームは8頭、JRA はそれより多いことが多い）の違いもあるが、頭数を12・16頭にしても1-2着の差はほとんど変わらなかったので、主な理由ではない。ゴール前で並ぶ形（追う馬が届きかけて競り合う展開）がまだ少ないと考えられるが、無理に接戦を作る処理は入れていない
- 英国の重賞（平地＋障害）の 1-2着 0.32% に対し、ゲームの重賞は 0.285%、全体は 0.337%。平地だけならもう少し小さいはずなので、下級条件はやや大きめの可能性がある
- 2400m の未勝利→重賞の差は 3.5%（実際は約2%）で、まだやや大きい。スタミナの差が長距離の配分に効くため
- 短距離は勝ち時計比が 0.47% と他の距離（0.24〜0.29%）より大きい。発馬と加速の差が距離に対して相対的に大きく出るため
- CPU馬の約25%は距離・馬場の適性が合わないまま出走する設定（v1.3 からの仕様）で、これが1着-最下位の差の大部分を占める。現実にどの程度いるかのデータがないので変えていない
- 道中で作戦より前に出てしまった差し・追込の馬が、そのまま先頭を走ることがある（長距離で配分の上限が効く場合）
