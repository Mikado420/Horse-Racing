# UI/UX 全面再設計：現状調査と設計（フェーズ1）

調査日：2026-10-23　ブランチ：`feature/ui-v4`（`feature/analysis-v2` の上）
調査方法：コードの読み取りと、実際の画面の撮影（横向きスマホ 844×390、縦向きスマホ 390×844、PC 1280×800）。

## 2. 主な問題

1. **ナビの名前が新しい構成と違う**：所有馬／出走／記録・分析。指示書の5項目は ホーム／愛馬／厩舎／レース／記録。
2. **ホームに情報が足りない**：牧場の絵が画面の大半を占めている。「今週の状況（所持金・頭数・予定）」「愛馬の状況」「最近の出来事」がまとまって見えず、横向きスマホでは ToDo が2件しか見えない。
3. **重要度の言葉が実際と合わない**：「新しい能力情報」や期限のない「出走計画」も「要確認」になっている。表示は「緊急／要確認／通常」で、指示書の「要対応／確認／お知らせ」と違う。
4. **報告が同じ提案で埋まる**：毎週の「出走の提案」がすべて「要確認」のカードになり、厩舎の報告欄が同じ文の繰り返しになる（未確認24件）。
5. **調教（育成方針）の場所が深い**：馬の詳細 →「育成・状態」タブにあり、選んだ瞬間に確定する（確定前の確認がない）。厩舎画面からは操作できない。
6. **愛馬一覧の一覧性が低い**：PC でもカードが3枚並ぶだけで、脚質・適性・直近の成績・次の予定が比べられない。
7. **馬の詳細（縦向き）**：大きな絵が先頭にあり、戦績や状態はスクロールしないと見えない。
8. **出走の流れが見えない**：今どの段階か（レース → 馬 → 確認 → 作戦 → 確定）が分からない。週の番組をレースから見る一覧もない。
9. **観戦中の差の表示**：「−3.2m」というメートル表示。中継らしい馬身の目安ではない。
10. **タブが狭い画面で切れる**：分析・馬の詳細のタブが横スクロールの奥に隠れる。
11. **一覧から詳細へ行って戻ると、スクロール位置が先頭に戻る。**

## 3. 新しいナビゲーションと画面構成

| 新しい項目 | 役割 | 旧画面との対応 |
|---|---|---|
| ホーム | 今週の状況・優先タスク・愛馬の状況・最近の出来事・次の週へ | ホーム（構成を変更）、お知らせ一覧の内容を統合 |
| 愛馬 | 一覧（PCは馬柱風の表、スマホは簡潔なカード）、詳細（タブで分類） | 所有馬一覧・馬の詳細。馬を買うは愛馬一覧とホームの補助操作 |
| 厩舎 | 調教（馬を選ぶ → 状態 → 方針を選ぶ → 確認して依頼）、報告、調教師 | 厩舎 ＋ 馬の詳細「育成・状態」の方針の変更 |
| レース | 今週の番組（レースから）、出走予定表（馬から）、出走計画（段階の表示つき） | 出走予定表・出走計画 |
| 記録 | 戦績（新聞の結果欄風）、レース分析、評価の推移、収支・名簿、検証 | 記録・分析 |

補助機能（メインのナビには増やさない）：
- お知らせ・設定：共通ヘッダー
- 馬を買う：ホームの「今週の状況」と愛馬一覧

ヘルプ画面は今は存在しないため、見た目だけの入口は作らない。

## 4. 既存機能との対応（なくさないもの）

- 牧場の絵：ホームの上部の細い帯に縮める（スマホ横向きでは高さを優先して出さない）。馬の名札から詳細に飛ぶ機能は、愛馬の状況の一覧に置き換える。
- 次の週へ／4週まとめて：ホームの主操作として残す。
- 報告の詳細シートと、提案への回答：そのまま残す。
- 目標レースの設定・提案の扱い：育成方針の変更画面に残す。
- PWA の更新ボタン、レース中の更新保護、セーブ状態の表示：ヘッダーにそのまま残す。
- レースの計算・勝敗・セーブの形式：変えない。

## 5. 重要度の表示

| 内部の値 | 新しい表示 | 使う場面 |
|---|---|---|
| urgent | 要対応 | 故障・疲労の蓄積・所持金がマイナス・現役の馬がいない |
| check | 確認 | 今週出られるレース、目標レースが近い、調教師からの回答待ちの提案 |
| normal | お知らせ | 新しい能力の見立て、未分析のレース、回答の要らない報告 |

## 6. ブレークポイント（既存の CSS と実際の内容から）

- 横向きスマホ：高さ 500px 以下の横長。左に細いメニュー、ヘッダーは低くする。
- 縦向きスマホ：幅 720px 未満。下にメニュー。表はカードにする。
- タブレット・PC：幅 720px 以上。表と複数カラムを使い、本文の最大幅は 1200px。
